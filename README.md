# Kas AI - Question & Answer App

## Project Overview

Kas AI is an AI-powered Question and Answer application built using Streamlit and Hugging Face. Users can enter questions and receive clear, simple, and educational answers generated by the Llama 3.1 8B Instruct model.

## Features

* Simple question and answer interface
* AI-generated answers
* Educational-focused responses
* Uses system and user roles
* Powered by Hugging Face
* Built with Streamlit
* Can be deployed using Streamlit Community Cloud

## Technologies Used

* Python
* Streamlit
* Hugging Face Hub
* Llama 3.1 8B Instruct
* Hugging Face Inference API

## Requirements

Install the required Python packages using:

```bash
pip install streamlit huggingface_hub
```

Or install them from the requirements file:

```bash
pip install -r requirements.txt
```

## Hugging Face API Token

This application requires a Hugging Face API token.

The application reads the token from an environment variable named:

```text
token
```

For local development in PowerShell:

```powershell
$env:token="your_hugging_face_token"
```

Do not add your actual token directly to the Python source code or upload it to GitHub.

## Running the Application Locally

Open the project folder in VS Code and run:

```bash
python -m streamlit run huggingfaceapp.py
```

The application will open in your browser at:

```text
http://localhost:8501
```

## How It Works

1. The user enters a question.
2. Streamlit receives the question.
3. The question is sent to the Hugging Face Inference API.
4. The system role defines Kas AI as an educational assistant.
5. The user role contains the user's question.
6. The Llama 3.1 8B Instruct model generates an answer.
7. The generated answer is displayed in the Streamlit application.

## Message Structure

The application uses two chat roles:

```python
messages=[
    {
        "role": "system",
        "content": "You are Kas AI, a helpful educational AI assistant."
    },
    {
        "role": "user",
        "content": question
    }
]
```

The system role defines how the AI should behave, while the user role contains the question entered by the user.

## Deployment

The application can be deployed using Streamlit Community Cloud.

### Deployment Steps

1. Upload the project to GitHub.
2. Make sure `huggingfaceapp.py` and `requirements.txt` are included.
3. Connect the GitHub repository to Streamlit Community Cloud.
4. Select `huggingfaceapp.py` as the main file.
5. Add the Hugging Face token in Streamlit Secrets.

The Streamlit Secret should be:

```toml
token = "your_hugging_face_token"
```

Do not store the Hugging Face token in the GitHub repository.

## requirements.txt

The `requirements.txt` file should contain:

```text
streamlit
huggingface_hub
```
